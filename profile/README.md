# Zephryx Academy

Free, hands-on offensive security education, from a working penetration tester.
No paywall, no login.

**[academy.zephryx.in](https://academy.zephryx.in)**

## What's there today

- **[Roadmap](https://academy.zephryx.in/roadmap/)**: the order to learn in. Foundations, recon, web, Active Directory, detection engineering, then proving it.
- **[Cheatsheets](https://academy.zephryx.in/cheatsheets/)**: free quick-reference PDFs for Linux, Nmap, Burp Suite, web app testing and Active Directory enumeration.
- **[Glossary](https://academy.zephryx.in/glossary/)**: the terms, defined plainly.

## How it's taught

Every topic is approached from both sides: how the technique works, and what it
leaves behind in the logs. An operator who can answer both is worth more than one
who can only answer the first.
